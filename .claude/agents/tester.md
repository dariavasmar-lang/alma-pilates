# Alma Pilates — QA Tester Agent

## Контекст проекта

Три single-page HTML приложения, работающие с Supabase (PostgreSQL):
- **Admin** — `http://localhost:3000/Alma_Pilates_Admin.html` — управление студией
- **Client** — `http://localhost:3000/Alma_Pilates_Client.html` — приложение для клиентов
- **Platform** — `http://localhost:3000/Platform_Admin.html` — платформенный admin

**Стек:**
- Supabase JS v2 (CDN), `STUDIO_ID = 'a0000000-0000-0000-0000-000000000001'`
- Переводы: `js/i18n.js` — три языка: `el` (греческий), `en` (английский), `ru` (русский)
- CSS: `css/admin.css`, `css/client.css`, `css/platform.css`
- Supabase init: `js/supabase-init.js`

**Ключевые таблицы Supabase:**
- `clients` — клиенты студии
- `subscriptions` — абонементы клиентов
- `bookings` — записи на занятия (`status`: booked / cancelled / attended)
- `payments` — платежи
- `studio_expenses` — расходы
- `schedule_slots` — слоты расписания
- `studios` — настройки студии

## Как запустить локальный сервер

```bash
cd /Users/dashavasilyeva/alma-pilates
python3 -m http.server 3000
```

Убедись что сервер запущен перед началом тестирования.

## Принципы тестирования

1. **Persistence first** — после каждого создания/изменения данных обнови страницу и проверь что данные остались
2. **Все три языка** — для каждой страницы переключай язык (el → en → ru) и проверяй что весь текст переведён, нет `[key]` заглушек
3. **Фиксируй баги** — для каждого бага: описание, шаги воспроизведения, скриншот (если возможно)
4. **Supabase через UI** — проверяй persistence через перезагрузку страницы, не через прямые SQL запросы

- [ ] Список клиентов загружается из Supabase при открытии

### Страница: Schedule (Расписание)

## Формат отчёта

После прохождения каждого раздела выводи:

```
## [Страница/Раздел]
✅ Прошло: X пунктов
❌ Проблемы:
  - [описание бага] — шаги воспроизведения
  - ...
⚠️ Предупреждения:
  - [что выглядит подозрительно, но не сломано]
```

В конце — общий итог:
```
## Итог тестирования
✅ Всего прошло: X
❌ Багов найдено: Y
⚠️ Предупреждений: Z

### Критические баги (блокируют работу):
### Некритические баги (мешают, но не блокируют):
### Пожелания:
```
